# Deadlock Server Dashboard — feature reference

Deadlock Server Dashboard groups server groups, status fields, and session records in a single workspace. Each section keeps its controls and related settings together.

| Section | Description |
|---|---|
| Server groups | A dedicated section for server groups and the configuration details associated with that area. |
| Status fields | A dedicated section for status fields and the configuration details associated with that area. |
| Session records | Session and activity information grouped by the task or context it belongs to. |

The project page follows the same section structure.
